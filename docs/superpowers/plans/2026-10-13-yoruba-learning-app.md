# Yoruba Project Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a web app that teaches Yoruba grammar to English speakers across five levels (20 lessons), each lesson an instruction page with component-by-component word breakdowns followed by an activity, with full tone marks throughout.

**Architecture:** A Vite + React single-page app. All curriculum lives in typed data files under `src/content/`, validated by a script and unit tests, so instruction pages and activities are rendered from one source of truth. Word contractions are hand-authored step lists (no rule engine). Progress and theme live in `localStorage` behind pure, testable functions.

**Tech Stack:** TypeScript, React, Vite, TanStack Router (code-based routes, SPA mode), Tailwind CSS v4 plus token-driven CSS, Vitest + Testing Library, Playwright, Cloudflare Workers (static assets).

**Spec:** `docs/superpowers/specs/2026-10-13-yoruba-learning-app-design.md`

**Deliberate deviation from the spec:** The spec says "same stack as LangLoop (TanStack Router/Start)". This plan uses TanStack Router in SPA mode on Workers static assets instead of TanStack Start SSR. The app is fully client-rendered with `localStorage` progress, so SSR adds hydration risk (LangLoop hit React error #418) with no benefit. If you want SSR for SEO later, the content and components carry over unchanged.

**Working directory for every command:** `~/Desktop/Professional/5_Projects and Gigs/Yoruba Project` (written `$YP` below). Quote the path in shell commands because it contains spaces.

## Global Constraints

- All Yoruba strings are stored NFC-normalized, with tone marks and under-dots: enforced by `validateLesson` and a unit test.
- No em dashes (U+2014) and no eyebrow labels in any copy, content, or design: enforced by `validateLesson` for content and by `no-em-dash.test.ts` for source files.
- Contractions are authored step lists, never generated by rules. Every newly drafted `WordBreakdown` has `confidence: "needs-review"` and a `note` naming the doubt. Only the owner flips a word to `"verified"`.
- Progress and theme are read from `localStorage` inside `useEffect`, never in a `useState` initializer. Every storage read and write is wrapped in try/catch and the app must render with storage unavailable.
- Both themes are dark-green in character and every text/background token pair passes WCAG AA (4.5:1): enforced by `contrast.test.ts`.
- Tone is never conveyed by color alone: chips carry a shape and a label.
- Real screenshots of the home page, an instruction page, and an activity in both themes are shown to the owner and approved before the visual design is treated as final (Task 10, Step 8).
- Anything that changes behavior needs a real check on localhost before any deploy. Never run `wrangler deploy` without the owner saying so (Task 16).
- Commit messages end with this trailer, added as a second `-m`: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`

## Review Focus

These are the inputs the spec implies but its main tests would not exercise. Each is pinned by a test in the named task.

1. Learner pastes or types an answer in decomposed (NFD) Unicode, which is common when copying Yoruba from the web: must still be graded correct. (Task 3)
2. `localStorage` is unavailable (private window) or holds corrupt JSON: the app must still render with empty progress and never throw. (Task 5)
3. A URL for a level or lesson that does not exist, or a level that is still locked: must show a friendly page with a way home, not a blank screen or crash. (Task 10)
4. `speechSynthesis` is missing entirely (some browsers, jsdom) or has no Yoruba voice: the audio button must disappear without errors. (Task 8)
5. Phone width (375px) with long tone-marked phrases and stacked breakdown tiles: no horizontal page scroll. (Task 16)

`src/lib/contrast.ts`:

```ts
function channel(v: number): number {
  const c = v / 255;
  return c <= 0.03928 ? c / 12.92 : Math.pow((c + 0.055) / 1.055, 2.4);
}

function luminance(hex: string): number {
  const n = parseInt(hex.replace("#", ""), 16);
  const r = (n >> 16) & 255;
  const g = (n >> 8) & 255;
  const b = n & 255;
  return 0.2126 * channel(r) + 0.7152 * channel(g) + 0.0722 * channel(b);
}

export function contrastRatio(a: string, b: string): number {
  const [hi, lo] = [luminance(a), luminance(b)].sort((x, y) => y - x) as [number, number];
  return (hi + 0.05) / (lo + 0.05);
}
```

```ts
  return readdirSync(dir).flatMap((name) => {
```

```ts
import type { Tone } from "@/content/types";

const ACUTE = "́";
const GRAVE = "̀";
const VOWELS = new Set(["a", "e", "i", "o", "u"]);
const isMark = (c: string | undefined): boolean => !!c && /[̀-ͯ]/.test(c);

type Letter = { base: string; text: string; tone: Tone };

function letters(word: string): Letter[] {
  const chars = Array.from(word.normalize("NFD"));
  const out: Letter[] = [];
  let i = 0;
  while (i < chars.length) {
    const first = chars[i]!;
    let base = first.toLowerCase();
    let text = first;
    i++;
    if (base === "g" && chars[i]?.toLowerCase() === "b") {
      base = "gb";
      text += chars[i]!;
      i++;
    }
    let tone: Tone = "mid";
    while (isMark(chars[i])) {
      const mark = chars[i]!;
      const next: Tone | null = mark === ACUTE ? "high" : mark === GRAVE ? "low" : null;
      if (next) {
        if (tone !== "mid" && tone !== next) throw new Error(`Conflicting tone marks in "${word}"`);
        tone = next;
      }
      text += mark;
      i++;
    }
    out.push({ base, text, tone });
  }
  return out;
}

const isVowel = (l: Letter | undefined): boolean => !!l && VOWELS.has(l.base);
const isNasalCoda = (n: Letter | undefined, after: Letter | undefined): boolean =>
  !!n && n.base === "n" && n.tone === "mid" && !isVowel(after);

export function syllabify(word: string): string[] {
  const ls = letters(word);
  const out: string[] = [];
  let i = 0;
  while (i < ls.length) {
    const l = ls[i]!;
    if (isVowel(l)) {
      let s = l.text;
      i++;
      if (isNasalCoda(ls[i], ls[i + 1])) {
        s += ls[i]!.text;
        i++;
      }
      out.push(s);
    } else if ((l.base === "n" || l.base === "m") && (l.tone !== "mid" || !isVowel(ls[i + 1]))) {
      out.push(l.text);
      i++;
    } else if (isVowel(ls[i + 1])) {
      let s = l.text + ls[i + 1]!.text;
      i += 2;
      if (isNasalCoda(ls[i], ls[i + 1])) {
        s += ls[i]!.text;
        i++;
      }
      out.push(s);
    } else {
      throw new Error(`Cannot syllabify "${word}" at "${l.text}"`);
    }
  }
  return out.map((s) => s.normalize("NFC"));
}

export function toneOf(syllable: string): Tone {
  const marked = letters(syllable).find((l) => l.tone !== "mid");
  return marked ? marked.tone : "mid";
}
```

```ts
export type AnswerKind = "correct" | "tone" | "mark" | "wrong";

export function checkAnswer(given: string, expected: string): AnswerKind {
  const g = cleanAnswer(given);
  const e = cleanAnswer(expected);
  if (g === e) return "correct";
  if (stripTones(g) === stripTones(e)) return "tone";
  if (stripMarks(g) === stripMarks(e)) return "mark";
  return "wrong";
}

    case "correct":

      return `Close. Check the dots under ẹ, ọ and ṣ. Answer: ${expected}`;
    case "wrong":
      return `Not quite. Answer: ${expected}`;
  }
}
```

```ts
function hash(seed: string): number {
  let h = 1779033703 ^ seed.length;
  for (let i = 0; i < seed.length; i++) {
    h = Math.imul(h ^ seed.charCodeAt(i), 3432918353);
    h = (h << 13) | (h >>> 19);
  }
  return h >>> 0;
}

function mulberry32(a: number): () => number {
  return () => {
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

export function seededShuffle<T>(items: readonly T[], seed: string): T[] {
  const out = [...items];
  const rand = mulberry32(hash(seed));
  for (let i = out.length - 1; i > 0; i--) {
    const j = Math.floor(rand() * (i + 1));
    [out[i], out[j]] = [out[j]!, out[i]!];
  }
  const same = out.every((v, i) => v === items[i]);
  if (same && out.length > 1) out.push(out.shift()!);
  return out;
}
```

```ts
import type { Lesson, Question, WordBreakdown } from "./types";

export const QUESTIONS_PER_LESSON = 8;
const EM_DASH = "—";
const ws = (s: string): string => s.replace(/\s+/g, "");

function* strings(v: unknown): Generator<string> {
  if (typeof v === "string") yield v;
  else if (Array.isArray(v)) for (const x of v) yield* strings(x);
  else if (v && typeof v === "object") for (const x of Object.values(v)) yield* strings(x);
}

export function validateBreakdown(w: WordBreakdown, ruleIds: Set<string>): string[] {
  const errors: string[] = [];
  const err = (m: string) => errors.push(`word "${w.id}": ${m}`);
  const joined = ws(w.parts.map((p) => p.text).join(""));

  if (w.parts.length === 0) err("has no parts");

  if (w.steps.length === 0) {
    if (joined !== ws(w.surface)) {
      err(`parts joined ("${joined}") differ from surface ("${w.surface}") and no steps explain the change`);
    }
  } else {
    const first = w.steps[0]!;
    if (first.kind !== "join") err("first step must be a join");
    else if (ws(first.result) !== joined) err(`join step result "${first.result}" does not match the parts "${joined}"`);
    const last = w.steps[w.steps.length - 1]!;
    if (last.result !== w.surface) err(`last step "${last.result}" does not equal the surface "${w.surface}"`);
    for (const s of w.steps) {
      if (s.kind !== "join" && !s.ruleId) err(`step "${s.result}" needs a ruleId`);
      if (s.ruleId && !ruleIds.has(s.ruleId)) err(`ruleId "${s.ruleId}" does not resolve to a rule in this lesson`);
    }
  }

  if (w.confidence === "needs-review" && !w.note) err("needs-review words need a note naming the doubt");
  return errors;
}

function validateQuestion(q: Question, n: number, wordIds: Set<string>): string[] {
  const errors: string[] = [];
  const err = (m: string) => errors.push(`question ${n + 1}: ${m}`);
  if (q.type === "blank") {
    if (!q.prompt.includes("___")) err('blank prompt needs a "___" gap');
    if (!q.choices.includes(q.answer)) err("answer is not among the choices");
    if (new Set(q.choices).size !== q.choices.length) err("choices contain duplicates");
  } else if (q.type === "pick") {
    if (!Number.isInteger(q.answer) || q.answer < 0 || q.answer >= q.choices.length) err("answer index is out of range");
    if (new Set(q.choices).size !== q.choices.length) err("choices contain duplicates");
  } else {
    const a = [...q.answer].sort().join("|");
    const b = [...q.words].sort().join("|");
    if (a !== b) err("order answer is not a permutation of words");
    if (q.answer.length < 2) err("order answer needs at least two words");
  }
  if ((q.type === "blank" || q.type === "pick") && q.wordId && !wordIds.has(q.wordId)) {
    err(`wordId "${q.wordId}" does not match any example`);
  }
  return errors;
}

export function validateLesson(lesson: Lesson): string[] {
  const errors: string[] = [];
  const err = (m: string) => errors.push(`${lesson.id}: ${m}`);

  for (const s of strings(lesson)) {
    if (s !== s.normalize("NFC")) err(`string is not NFC: "${s}"`);
    if (s.includes(EM_DASH)) err(`string contains an em dash: "${s}"`);
  }
  if (lesson.sources.length === 0) err("sources is empty");
  if (lesson.questions.length !== QUESTIONS_PER_LESSON) {
    err(`expected ${QUESTIONS_PER_LESSON} questions, found ${lesson.questions.length}`);
  }
  if (lesson.primer.examples.length < 3) err("needs at least 3 examples");

  const ruleIds = new Set(lesson.primer.rules.map((r) => r.id));
  const wordIds = new Set(lesson.primer.examples.map((e) => e.id));
  for (const w of lesson.primer.examples) for (const e of validateBreakdown(w, ruleIds)) err(e);
  lesson.questions.forEach((q, n) => {
    for (const e of validateQuestion(q, n, wordIds)) err(e);
  });
  return errors;
}
```

`src/lib/progress.ts`:

```ts
export type ThemeChoice = "system" | "light" | "dark";

export type Progress = {
  completedLessons: Record<string, { bestScore: number; completedAt: string }>;
  skipAhead: boolean;
  theme: ThemeChoice;
};

export const emptyProgress: Progress = { completedLessons: {}, skipAhead: false, theme: "system" };

const KEY = "yp:progress:v1";
const THEMES: ThemeChoice[] = ["system", "light", "dark"];

function defaultStorage(): Storage | null {
  try {
    return globalThis.localStorage ?? null;
  } catch {
    return null;
  }
}

export function loadProgress(storage: Storage | null = defaultStorage()): Progress {
  try {
    const raw = storage?.getItem(KEY);
    if (!raw) return emptyProgress;
    const v = JSON.parse(raw) as Partial<Progress>;
    if (!v || typeof v !== "object" || !v.completedLessons || typeof v.completedLessons !== "object") {
      return emptyProgress;
    }
    return {
      completedLessons: v.completedLessons,
      skipAhead: v.skipAhead === true,
      theme: THEMES.includes(v.theme as ThemeChoice) ? (v.theme as ThemeChoice) : "system",
    };
  } catch {
    return emptyProgress;
  }
}

export function saveProgress(p: Progress, storage: Storage | null = defaultStorage()): void {
  try {
    storage?.setItem(KEY, JSON.stringify(p));
  } catch {
    // Storage can be blocked (private windows). Progress simply will not persist.
  }
}

export function recordCompletion(p: Progress, lessonId: string, score: number, now: Date = new Date()): Progress {
  const prev = p.completedLessons[lessonId];
  const bestScore = prev ? Math.max(prev.bestScore, score) : score;
  return {
    ...p,
    completedLessons: {
      ...p.completedLessons,
      [lessonId]: { bestScore, completedAt: prev?.completedAt ?? now.toISOString() },
    },
  };
}

export function isLevelUnlocked(
  levels: { id: string; lessons: { id: string }[] }[],
  p: Progress,
  levelId: string,
): boolean {
  const idx = levels.findIndex((l) => l.id === levelId);
  if (idx === -1) return false;
  if (idx === 0 || p.skipAhead) return true;
  return levels[idx - 1]!.lessons.every((l) => p.completedLessons[l.id]);
}
```

```ts
import { useCallback, useEffect, useState } from "react";
import { emptyProgress, loadProgress, saveProgress, type Progress } from "@/lib/progress";
import { applyTheme } from "@/lib/theme";

// Starts empty and loads in an effect so server and client first renders match.
export function useProgress() {
  const [progress, setProgress] = useState<Progress>(emptyProgress);

  useEffect(() => {
    const p = loadProgress();
    setProgress(p);
    applyTheme(p.theme);
  }, []);

  const update = useCallback((fn: (p: Progress) => Progress) => {
    // Reload first so a theme change made elsewhere is never overwritten by stale state.
    const next = fn(loadProgress());
    saveProgress(next);
    applyTheme(next.theme);
    setProgress(next);
  }, []);

  return { progress, update };
}
```

```ts
import type { Level } from "@/content/types";

export function buildReviewMarkdown(levels: Level[]): string {
  const lines: string[] = [];
  let total = 0;

  for (const level of levels) {
    const lessonBlocks: string[] = [];
    for (const lesson of level.lessons) {
      const items = lesson.primer.examples.filter((w) => w.confidence === "needs-review");
      if (items.length === 0) continue;
      total += items.length;
      lessonBlocks.push(`### ${lesson.title} (\`${lesson.id}\`)`);
      lessonBlocks.push(`Sources consulted: ${lesson.sources.join("; ")}`);
      lessonBlocks.push("");
      for (const w of items) {
        lessonBlocks.push(`- \`${w.id}\`: **${w.surface}** (${w.english})`);
        lessonBlocks.push(`  - Parts: ${w.parts.map((p) => p.text).join(" + ")}`);
        if (w.steps.length) lessonBlocks.push(`  - Steps: ${w.steps.map((s) => s.result).join(" > ")}`);
        lessonBlocks.push(`  - Doubt: ${w.note ?? "(none recorded)"}`);
      }
      lessonBlocks.push("");
    }
    if (lessonBlocks.length) lines.push(`## ${level.title}`, "", ...lessonBlocks);
  }

  const header = [
    "# Content review list",
    "",
    "Generated by `npm run review`. Do not edit by hand.",
    "",
    total === 0 ? "All items are verified." : `${total} item${total === 1 ? "" : "s"} need review.`,
    "",
  ];
  return [...header, ...lines].join("\n");
}
```

```ts
import { useEffect, useState } from "react";

function findVoice(): SpeechSynthesisVoice | null {
  try {
    const synth = globalThis.speechSynthesis;
    if (!synth) return null;
    return synth.getVoices().find((v) => v.lang.toLowerCase().startsWith("yo")) ?? null;
  } catch {
    return null;
  }
}

export function useYorubaVoice(): SpeechSynthesisVoice | null {
  const [voice, setVoice] = useState<SpeechSynthesisVoice | null>(null);
  useEffect(() => {
    const synth = globalThis.speechSynthesis;
    setVoice(findVoice());
    if (!synth?.addEventListener) return;
    const onChange = () => setVoice(findVoice());
    synth.addEventListener("voiceschanged", onChange);
    return () => synth.removeEventListener("voiceschanged", onChange);
  }, []);
  return voice;
}
```

```tsx
import { useState } from "react";
import type { Question } from "@/content/types";
import { checkAnswer, feedbackFor, type AnswerKind } from "@/lib/answer";
import { ChoiceQuestion } from "./ChoiceQuestion";
import { OrderQuestion } from "./OrderQuestion";

export type ActivityResult = { correct: number; total: number; missed: Question[] };

function expectedOf(q: Question): string {
  if (q.type === "blank") return q.answer;
  if (q.type === "pick") return q.choices[q.answer]!;
  return q.answer.join(" ");
}

export function Activity({ questions, onDone }: { questions: Question[]; onDone: (r: ActivityResult) => void }) {
  const [i, setI] = useState(0);
  const [chosen, setChosen] = useState<string | null>(null);
  const [kind, setKind] = useState<AnswerKind | null>(null);
  const [correct, setCorrect] = useState(0);
  const [missed, setMissed] = useState<Question[]>([]);

  const q = questions[i]!;
  const expected = expectedOf(q);
  const answered = kind !== null;
  const last = i === questions.length - 1;

  function submit(given: string) {
    const k = checkAnswer(given, expected);
    setChosen(given);
    setKind(k);
    if (k === "correct") setCorrect((c) => c + 1);
    else setMissed((m) => [...m, q]);
  }

  function next() {
    if (last) {
      onDone({ correct, total: questions.length, missed });
      return;
    }
    setI(i + 1);
    setChosen(null);
    setKind(null);
  }

  return (
    <section style={{ display: "grid", gap: "1rem" }}>
      <div className="progressbar" role="progressbar" aria-valuemin={0} aria-valuemax={questions.length} aria-valuenow={i + 1}>
        <div style={{ width: `${((i + (answered ? 1 : 0)) / questions.length) * 100}%` }} />
      </div>
      <p className="muted" style={{ margin: 0 }}>Question {i + 1} of {questions.length}</p>

      {q.type === "order" ? (
        <OrderQuestion key={i} english={q.english} words={q.words} seed={`${i}:${q.answer.join("")}`} disabled={answered} onSubmit={submit} />
      ) : (
        <ChoiceQuestion
          key={i}
          prompt={q.prompt}
          choices={q.choices}
          chosen={chosen}
          correct={expected}
          onChoose={submit}
        />
      )}

      {answered && (
        <div className="card" role="status" style={{ borderColor: kind === "correct" ? "var(--accent)" : "var(--danger)" }}>
          <p style={{ margin: 0 }} className="yo">{feedbackFor(kind, expected)}</p>
        </div>
```

```tsx
import { useState } from "react";
import { Link, useParams } from "@tanstack/react-router";
import { Activity, type ActivityResult } from "@/components/Activity";
import { NotFound } from "@/components/NotFound";
import { Primer } from "@/components/Primer";
import { Results } from "@/components/Results";
import { LEVELS, getLesson, getLevel, nextLessonPath } from "@/content/levels";
import type { Question } from "@/content/types";
import { useProgress } from "@/hooks/useProgress";
import { isLevelUnlocked, recordCompletion } from "@/lib/progress";

type View =
  | { name: "primer" }
  | { name: "activity"; questions: Question[]; attempt: number }
  | { name: "results"; result: ActivityResult };

export function LessonPage() {
  const { levelId, lessonId } = useParams({ strict: false }) as { levelId: string; lessonId: string };
  const { progress, update } = useProgress();
  const [view, setView] = useState<View>({ name: "primer" });
  const [showPrimer, setShowPrimer] = useState(false);

  const level = getLevel(levelId);
  const lesson = getLesson(levelId, lessonId);
  if (!level || !lesson) return <NotFound what="lesson" />;
  if (!isLevelUnlocked(LEVELS, progress, level.id)) return <NotFound what="lesson" />;

  function finish(result: ActivityResult, wasFullRun: boolean) {
    if (wasFullRun) update((p) => recordCompletion(p, lesson!.id, result.correct / result.total));
    setView({ name: "results", result });
  }

  return (
    <main className="page" style={{ display: "grid", gap: "1rem" }}>
      <Link to="/level/$levelId" params={{ levelId: level.id }}>{level.title}</Link>
      <h1 style={{ margin: 0 }}>{lesson.title}</h1>

      {view.name === "primer" && (
        <Primer
          lesson={lesson}
          onStart={() => setView({ name: "activity", questions: lesson.questions, attempt: 0 })}
        />
      )}

      {view.name === "activity" && (
        <>
          <button className="btn" onClick={() => setShowPrimer((s) => !s)}>
            {showPrimer ? "Hide instructions" : "Show instructions"}
          </button>
          {showPrimer && <Primer lesson={lesson} />}
          <Activity
            key={view.attempt}
            questions={view.questions}
            onDone={(r) => finish(r, view.questions.length === lesson.questions.length)}
          />
        </>
      )}

      {view.name === "results" && (
        <Results
          correct={view.result.correct}
          total={view.result.total}
          missedCount={view.result.missed.length}
          levelId={level.id}
          next={nextLessonPath(level.id, lesson.id)}
          onReviewInstructions={() => setView({ name: "primer" })}
          onRetryMissed={() =>
            setView({ name: "activity", questions: view.result.missed, attempt: Date.now() })
          }
        />
      )}
    </main>
  );
}
```

## Content authoring (Tasks 11 to 15)

These five tasks author the remaining 19 lessons. They share one procedure, stated once here and referenced by each task. Each lesson file has exactly the shape of `src/content/lessons/gs-1.ts` (Task 7), exported as a named constant, and must satisfy `validateLesson`.

**Authoring procedure (applies to every lesson in Tasks 11 to 15):**

1. Create the lesson file `src/content/lessons/<id>.ts` shaped exactly like `gs-1.ts`, with `id`, `level`, `title`, `sources`, `primer` (`rule`, `formula`, `rules`, `examples`, `commonMistake`, optional `toneFocus`) and exactly 8 `questions`.
2. Question mix per lesson: 3 `blank`, 2 `pick`, 3 `order`. Every `blank` and `pick` that tests a primer word sets `wordId`. Distractors are tone variants or dot-less spellings of the correct answer wherever the lesson is about tone or marks, so the tone-aware feedback is exercised.
3. Examples: at least 3 `WordBreakdown`s, built from the lesson brief's seed words. Use real morphemes (not syllables) for `parts` from Beginner onward. For any contraction, write each step by hand and give it a `ruleId` that exists in the lesson's `rules`.
4. Every word starts as `confidence: "needs-review"` with a `note` naming the specific doubt (tone, contraction, regional variant, or gloss). Never set `"verified"`.
5. `sources`: list what the content was cross-checked against. If it could not be cross-checked, say so in plain words (for example "Not yet cross-checked against a published grammar").
6. Register the lesson in `src/content/levels.ts` by importing it and adding it to its level's `lessons` array in lesson order.
7. Run `npm run validate`, then `npx vitest run src/content`, then `npm run review`. Fix the data until all pass.
8. Localhost check: open each new lesson, step through every breakdown, run the activity, and look at tone-mark rendering. Fix any clipped marks.
9. Commit the lesson files, `levels.ts`, and `content/REVIEW.md`.

Seed words below are the author's best recollection and are **starting points, not verified facts**. Where a brief says "find more", cross-check in a published Yoruba grammar or dictionary and record what was used in `sources`. If a seed cannot be confirmed, keep it, keep it `needs-review`, and state the doubt in `note`.

```ts
import { expect, test, type Page } from "@playwright/test";

const LEVEL_IDS = ["getting-started", "beginner", "intermediate", "advanced", "mastery"];

async function unlockAll(page: Page) {
  await page.addInitScript(() =>
    localStorage.setItem("yp:progress:v1", JSON.stringify({ completedLessons: {}, skipAhead: true, theme: "system" })),
  );
}

async function answerEverything(page: Page) {
  for (let n = 0; n < 8; n++) {
    const choice = page.getByTestId("choice").first();
    if (await choice.count()) {
      await choice.click();
    } else {
      const bank = page.getByTestId("bank-word");
      while (await bank.count()) await bank.first().click();
      await page.getByRole("button", { name: "Check" }).click();
    }
    await page.getByRole("button", { name: /^(Continue|See results)$/ }).click();
  }
}

for (const scheme of ["light", "dark"] as const) {
  test.describe(`${scheme} mode`, () => {
    test.use({ colorScheme: scheme });

    for (const levelId of LEVEL_IDS) {
      test(`complete the first lesson of ${levelId}`, async ({ page }) => {
        await unlockAll(page);
        await page.goto(`/level/${levelId}`);
        await page.getByRole("link", { name: /Lesson 1/ }).click();
        await page.getByRole("button", { name: "Start practice" }).click();
        await answerEverything(page);
        await expect(page.getByRole("heading", { name: "Results" })).toBeVisible();
        await page.goto(`/level/${levelId}`);
        await expect(page.getByText(/best \d+%/)).toBeVisible();
      });
    }
  });
}

test.describe("phone width", () => {
  test.use({ viewport: { width: 375, height: 800 } });

  for (const path of [
    "/",
    "/level/getting-started",
    "/lesson/getting-started/gs-1",
    "/lesson/getting-started/gs-3",
    "/lesson/mastery/m-4",
    "/about",
  ]) {
    test(`no horizontal scroll at ${path}`, async ({ page }) => {
      await unlockAll(page);
      await page.goto(path);
      for (const b of await page.getByRole("button", { name: "Show all" }).all()) await b.click();
      const overflow = await page.evaluate(() => document.documentElement.scrollWidth - document.documentElement.clientWidth);
      expect(overflow).toBeLessThanOrEqual(0);
    });
  }

  test("the app still renders when localStorage is blocked", async ({ page }) => {
    await page.addInitScript(() => {
      Object.defineProperty(window, "localStorage", { get() { throw new Error("blocked"); } });
    });
    await page.goto("/");
    await expect(page.getByRole("heading", { name: "Learn Yoruba grammar" })).toBeVisible();
  });
});
```
